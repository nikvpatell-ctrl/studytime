StudyTime is a Bash program that helps students manage their study time across different classes. It allows users to create their own study schedules based on how much time they want to spend on each subject.

Project Goal: The goal of StudyTime is to help students better organize their studying. Since some classes require more time than others, the program gives users a way to plan their study time and make adjustments whenever their priorities change.

MVP Features: The program will allow users to add classes, set how much time they want to study for each one, and view their schedule along with the total study time. Users will also be able to change their study times and save their schedules so they can access them again later.
Tech Stack: StudyTime will be written in Bash and developed using Ubuntu Linux. It will use commands such as read, echo, printf, awk, and sort. Study schedules will be stored in a CSV file, and Git and GitHub will be used for version control.


Future:Once the main features are working, I plan to add a timer that users can follow during their study sessions. I also want to add a way to mark sessions as completed, view weekly study summaries, and receive reminders to take breaks.
